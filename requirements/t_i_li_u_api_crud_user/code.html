api

Detailed Endpoints

GET

/users

Truy xuất danh sách người dùng có hỗ trợ phân trang và tìm kiếm.

QUERY PARAMETERS
  • page (int) - Default: 1
  • limit (int) - Default: 10
  • search (string) - Search by name or email
EXAMPLE FETCH 
fetch('https://api.example.com/v1/users?page=1&limit=20', {
  headers: { 'Authorization': 'Bearer YOUR_TOKEN' }
})
.then(res => res.json())
.then(data => console.log(data));
